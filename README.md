ภาษาที่ใช้ Python 3.13.3 โดยใช้เครื่องมือ FastAPI
ขั้นตอนการติดตั้ง หลังจาก Clone มาแล้ว  คือ 1.สร้าง .venv มาก่อน 2.pip install requirement.txt 3.ทดสอบรันด้วย fastapi run main.py  4.เข้าไปที่ http://127.0.0.1:8000/docs# เพื่อ ดูข้อมูล ใน docs หรือ swagger แทน
